# 충전 중 오프라인 통합·진단·강화학습 개선 작업지시서

작성일: 2026-11-21 · 버전: v0.2 · 상태: 일부 PC 모의 구현·검증 완료 / 실물 동작 금지 — 최신 결과는 10절

## 1. 이번 작업의 권한과 완료 범위

사용자는 연결을 복구했지만 **배터리 충전 중 모든 실물 구동 중단**을 지시했다. PC 문서·코드·모의 시험·재생만 갱신한다. 연결/충전 복구는 시작 권한이 아니다. 모터·리프트·GPIO/PWM·점검 펄스·자동 ARM/RESET·실제 센서 취득·포트 열기·자동 서비스 시작을 금지한다. 팀원 프로세스·배선·권한·서비스를 바꾸지 않는다.

최종 목적은 ID 확인→접근·정렬→삽입·들기→운반→적치·분리→DB 기록이다. 이번 완료는 **오프라인 계약·보정 검증·실패 분석** 범위다. 실물 미확인 단계는 PENDING/UNKNOWN을 유지한다.

기준: [기존 통합 지시서](autonomy_integration_work_order_20261121.md), Notion 40페이지 manifest(로컬 `outputs/rl_resume_20261121/notion_review.json`), [RL 안내](../autonomy_lab/README.md), [Notion 후속 지시서](https://app.notion.com/p/41f1cdebb6a581dfb891d81c66aec43b). manifest의 실측표·통합 검토 원문을 함께 따른다. 과거 “RL 미구현”과 아래 새 실험의 시점을 구분한다.

## 3. 공통 계약과 재생 규칙

관측은 최소 `schema_version, source_id, sensor_kind, physical_mount_id, frame_id, sequence, sample_monotonic_s, receive_monotonic_s, clock_domain, session_id, units, validity, quality, quality_kind, calibration_version`을 가진다. 거리 관측에는 `distance_m, uncertainty_m, direction_rad, fov_rad`를 추가한다. 원시값·변환값·출처를 보존하고 NaN/무한대·음수 거리·범위 밖 quality를 거절한다. 확률과 점수를 구분한다.

clock_domain 변환·offset 오차가 없으면 교차 시각 비교는 UNKNOWN이다. source별 순번, 중복·역순·미래 시각·sample≤receive·session 변경을 검사한다. 재수신으로 age를 갱신하지 않는다. 재생은 가상 단조 시계로 기록상 age를 계산한다.

각 스트림은 별도로 만료한다. 최신 초음파 소스는 4채널 대기만 0.4초 이상이므로 기존 200ms 신선도와 충돌한다. 시각 덮어쓰기·임계값 완화로 숨기지 않고 합성 fixture로 드러낸다. 실제 주기는 미측정이다.

입력은 JSON/JSONL·명시된 파일 목록으로 한정한다. manifest에 event ID·SHA256·synthetic/recorded·단위/frame/clock/schema를 둔다. 알 수 없는 종류·누락·범위 밖 파일 참조는 거절한다. 입력의 명령/URL/장치 경로를 실행하지 않으며 보기·seek·재시작은 action/ARM을 만들지 않는다.

`integration_contracts/observations.py`는 검사 상태·사유·원 증거·fixture 결과를 출력한다. `actual_motion_permission=false`다. 증거 충족 표시는 실물 허가가 아니며 센서 취득·융합 추정·제동·학습은 별도다.

## 4. A01–A10 작업별 실행 계약

각 작업에 입력/출력 버전·의존성·시험 ID·결과·증거 경로를 남긴다. 아래 인수는 소프트웨어 채택 기준이다.

### A01 · 세 센서 동시 관측과 재생

- 입력: 등록된 카메라 프레임 참조, LiDAR scan, 방향별 초음파, source별 시각·유효성.
- 출력: 원시 3종·상면도·사각·age·모드·공통 시간선. 미수신/STALE/UNKNOWN은 별도 표시.
- 의존: 공통 schema와 A06 보정. 먼저 텍스트/JSON 검사기를 만들고 화면 어댑터를 연결한다.
- 시험 T01: 한 센서 누락, 정지 영상 반복, 10배 재생·seek·일시정지, session 변경, 표시 중 오류.
- 인수·증거: 기록 시각에 맞는 상태 전이와 원본 해시 보존; 화면 캡처·fixture JSON·콘솔 오류 기록. 아직 화면 통합 전이면 검사기만 완료로 보고한다.
- 금지: 실제 센서로 표시하기, 모의 광선으로 실제 LiDAR 수신을 대체하기, 화면 열기로 제어권 얻기.

### A02 · 멈춤·회전 실패 진단

- 입력: 요청 행동→감독기 판정→적용 행동→합성/기록 관측, 기한·배터리 계측 유무.
- 출력: 의도된 정지/통신·시각/제어/전기·기계/추정/미확정의 복수 가설, 근거·반증·추가 측정.
- 의존: A01 시간선, 사건 ID. T02는 TTL 만료·센서 정지·전후 왕복·한쪽 응답 차이의 합성 사례.
- 인수·증거: STOP/거절을 기계 고장으로 단정하지 않고, 계측 없는 저전압은 미확정; 판정 JSON과 사건 전후 trace.
- 금지: 원인 미확정 상태에서 PWM·동작시간 증가나 보호정지 제거를 수정안으로 자동 적용.

### A03 · 집기·적치 실패와 성공 판정

- 입력: 임무 단계, 물품 ID, 포크/물품 상대 자세, 지지·탑재·분리 증거와 각각의 출처.
- 출력: 단계 상태, VERIFIED/FAILED/UNKNOWN, 필요한 추가 관측. LIFT 명령 ACK는 탑재 증거가 아니다.
- 의존: A07 외곽·A08 높이. T03은 빈 포크 상승, 포크 걸림, 가짜 완료, 지지 후 회수·최종 분리, ID 중복.
- 인수·증거: 독립 증거 없는 완료·보너스가 0건, 동일 단계 보상 중복 방지; 상태 전이표·event 로그.
- 금지: 현재 리프트 없는 RL 결과를 집기 학습 성공으로 보고하거나, 과거 이상적 높이 모델을 현물로 표시.

### A04 · 겹침·사각·상충과 상관된 센서

- 입력: FOV·높이·가림·시각 오차, 원시 측정과 source/correlation 그룹.
- 출력: 점유/자유/UNKNOWN 및 CONFLICT, 독립 출처 수, 이동 방향별 관측 부족 사유.
- 의존: A06 공통 frame. T04는 가까운 초음파+먼 LiDAR, 낮은 물체, 화물 가림, 같은 raw scan의 RF2O/SLAM.
- 인수·증거: 동일 표적·공통 좌표·단위·허용 시각 차이로 정규화된 comparison group만 비교한다. 상충을 평균으로 지우지 않고 원 증거를 보존한다.
- 금지: timeout=자유 공간, 같은 센서 파생값을 여러 표로 중복 신뢰. 동일 전원/USB/clock 장애는 공통 원인으로 별도 확장한다.

### A05 · 독립 보상과 제한된 학습

- 입력: 고정 관측/행동/보상/종료 정의, 감독기 개입, train/validation/evaluation 분할.
- 출력: 후보 정책·Q/체크포인트, 요청/적용 행동, 보상 성분·제약 위반, 기준기와 조건별 비교.
- 의존: 5절 개선 절차. T05는 반복 단계 보상, 영구 STOP, stale 성공, 평가 중 Q 변경, 종료와 time-limit truncation.
- 인수·증거: 평가 epsilon=0·업데이트 금지·전후 정책 해시 동일; 안전 기준 불변과 성능 판정 근거를 함께 충족.
- 금지: 실물 탐색, 정책이 보상 정의/안전 임계값 변경, 감독기 STOP의 무사고를 위험 요청의 성공으로 학습.

### A06 · 좌표·방향·시각 보정

- 입력: 원점·전방 규약, 부모/자식 frame, m/rad 단위, 변환·불확실성·기준 표적·보정 버전.
- 출력: 검증된 후보 transform 또는 거절 사유. 실제 x 전방/y 좌측/z 위와 optical 규약을 명시한다.
- 의존: 센서 등록부. T06은 단위 mm/m, 좌우 반사, yaw 부호, 180°영상 표시, 누락/순환 frame, 비정상 회전행렬.
- 인수·증거: 유한값·회전 정규성·det≈+1·변환 왕복·표적 잔차 검사. fixture 허용 오차는 config에 고정하며 현물 정확도로 표현하지 않는다.
- 금지: 코드 채널명·영상 회전만으로 실제 전후 판정, 운전 중 외부 보정 자동 교체.

### A07 · 외곽·회전·정지 영역

- 입력: 차체·포크·화물 도형, 높이 범위, 측정 여부·오차, pose/정지거리 불확실성.
- 출력: 보수 외곽과 회전 이동 영역, 확대 후보·충돌 사유. 모델 가정과 실측을 분리한다.
- 의존: A06/A08. T07은 포크 끝 돌출, 회전 측면 충돌, 낮은 장애물, 적재 외곽 확대, 잘못된 자동 축소.
- 인수·증거: 증가한 불확실성에서 보호 영역이 작아지지 않음; 경계 fixture·최소 여유·설정 해시.
- 금지: 영상/거리만으로 미관측 후면까지 정밀 추정했다고 선언, 단순 사각형 검사를 3D 충돌 전체 보장으로 확대.

### A08 · 무엔코더 이동과 리프트 UNKNOWN

- 입력: 위치 관측 가능성, 검증된 reference/limit 증거, session과 전원 복귀 기록.
- 출력: 위치·높이의 구간 또는 UNKNOWN, 불가능한 행동 사유. PWM×시간은 거리·높이의 실측값이 아니다.
- 의존: 실제 기준점은 미확인. T08은 부팅/재부팅, 저장 높이만 존재, 상하한 동시 ON, 한계 고착·단선, 수동 이동.
- 인수·증거: 검증된 기준 없이 lift UNKNOWN 유지, 동작 허가 false; 상태표·가짜 증거 출처·모순 검사 결과.
- 금지: 끝까지 밀어 homing, 접촉 하나로 양쪽 끝단/하중/높이 판정, 이번 턴 리프트 실제 구동.

### A09 · 수정 후보·검증·복귀

- 입력: 사건 묶음, 현재 소스/설정/정책, 최소 재현, 한 가지 원인 가설.
- 출력: 변경 후보·영향 요구 ID·회귀 결과·이전 버전 복귀 절차.
- 의존: A02와 고정 비교 세트. T09는 설정 손상, 체크포인트 해시 불일치, 로그 저장 실패, 후보 로드 실패.
- 인수·증거: 이전 결과 불변, 실패 후보 채택 안 함, 오프라인 복원 재현. 소스·설정·정책 중 바뀐 요소를 표시한다.
- 금지: 운전 중 hot patch, 새 Health로 예전 permit 연장, 자동 ARM/RESET, 팀 서비스 재시작.

### A10 · 팀 보호와 Notion 변경 추적

- 입력: 기존 manifest 40페이지와 관련 최신 원문, 팀 소스 해시·담당 인터페이스.
- 출력: 변경/충돌/채택/보류 목록, 소유 경로, 새 증거·PR 연결.
- 의존: 실제 접근 가능한 자료. T10은 문서 변경, 권한 없음, 누락 첨부, 두 버전 핀 충돌, 원본 해시 변화.
- 인수·증거: 시작·후보 채택·배포 전에 비교; 못 읽은 범위와 truncation 미제공을 공개. 이 담당 작업에서는 Notion을 수정하지 않는다.
- 금지: 수정일만으로 최신 배선 채택, 개인 계정/인증 복사, 40페이지 검토를 전체 Notion·첨부 완독으로 표시.
