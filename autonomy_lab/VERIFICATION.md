# 강화학습·입력 계약 검증 기록

검증일: 2026-11-21. 상태: **모의 접근·정렬 학습 및 오프라인 입력 계약 검증 완료 / 실물 자율주행·물품 취급 미검증**.

학습과 검증은 개인 PC에서 수행했습니다. 배터리 충전으로 실물 동작을 금지한 이후 모터·리프트·GPIO 출력 시도는 0회입니다. 기존 팀원 제어 코드와 실행 중인 제어 프로세스를 변경하거나 종료하지 않았습니다.

## 실험 범위

실험은 가정한 1.8×1.8m 평면 공간에서 목표 상대 거리·방향·헤딩의 합성 관측을 받아 접근 → 정렬 → STOP을 수행합니다. 기본 평가에는 내부 장애물이 없습니다. 차체·포크 외곽과 마찰/응답 편차는 실측값이 아닙니다. 리프트, 화물 접촉·하중·전도, 실제 영상 인식, 실제 LiDAR/초음파 융합을 학습하지 않았습니다.

정지는 즉시 속도0이 되는 모의 가정이며, 외곽 충돌이 예상되는 요청은 별도 감독기가 실행 전에 차단합니다. 모델에서 충돌0회라는 결과를 실물 안전 보장으로 사용하지 않습니다.

## 실제 수행한 학습

| 항목 | 기존 Q 정책 | 단계 기억 후보 |
| --- | --- | --- |
| 알고리즘 | tabular Q-learning v2 | 단계 기억·행동 제한 규칙 + Q-learning |
| 학습 에피소드 | 2,500 | 2,500 |
| 실제 Q 업데이트 | 249,689 | 236,672 |
| 학습 환경 seed | 0~999999에서 추출 | 0~999999에서 추출 |
| 원본 환경·보상 변경 | 기준 버전 | 기존 `environment.py`·`learning.py` 동결 유지 |

후보는 접근과 정렬 사이에 정지 단계를 넣고 단계 기억·히스테리시스·허용 행동 제한을 추가했습니다. 규칙, 상태 표현, 학습이 함께 변경되었으므로 성능 차이를 RL만의 효과라고 분리해 주장할 수 없습니다.

학습은 실제 관측된 감독기 적용 결과를 사용하며 요청 행동과 적용 행동을 구분합니다. 실제 종료에서는 bootstrap하지 않고 시간 제한에서는 유지합니다. 평가는 탐색 없이 수행하고 Q 배열의 평가 전후 해시가 변하지 않는지 검사합니다. 체크포인트에는 Q 값, RNG, 완료 에피소드, 설정·소스 해시가 포함되며 pickle을 사용하지 않습니다.

## 평가 결과

### 기존 정책의 첫 최종 평가

미사용 seed 3000000–3000079를 사용한 80건 결과입니다.

| 정책 | 성공 | 평균 step |
| --- | --- | --- |
| 기존 학습 정책 | 72/80, 90% | 41.375 |
| 미학습 Q=0 정책(STOP) | 0/80 | 160 |
| 비학습 기하 기준기 | 80/80, 100% | 29.625 |

기존 정책 실패는 시간 제한 7건과 예상 외곽 충돌 차단 1건입니다. 차단된 요청이 실제 움직임으로 적용된 것은 아닙니다. 이 실패 조건을 후보 설계에 참고했으므로 같은 seed는 후보에게 독립 최종 평가가 아닌 **회귀 평가**입니다.

후보의 같은 3000000대 회귀 평가는 **80/80 성공**, 평균29.675step이었습니다. 이 결과만으로 일반화 성능을 확정하지 않았습니다.

### 후보 동결 후 새 최종 평가

새로운 seed 4000000–4000079에서 후보와 대조 정책을 동일 조건으로 비교했습니다.

| 정책 | 성공 | 평균 step |
| --- | --- | --- |
| 단계 기억 + Q 후보 | 80/80, 100% | 29.9375 |
| 동결된 기존 Q 정책 | 75/80, 93.75% | 39.9875 |
| 비학습 기하 기준기 | 80/80, 100% | 29.5875 |
| 단계 기억 규칙만 사용 | 80/80, 100% | 30.0125 |
| 미학습 Q=0 정책 | 0/80 | 160 |

후보는 기존 Q 정책의 실패를 줄였으나 비학습 기준기의 성공률을 넘지 않았고 평균 step도 더 큽니다. 따라서 **RL 우월성, 실물 정책 승격, 전체 자율 지게차 완성으로 판단하지 않습니다.** 새 최종 평가를 본 뒤 해당 seed에 맞춰 후보를 다시 튜닝하지 않았습니다.

## 시험과 입력 계약

- 학습·후보·센서 계약 관련 단위시험: **31개 통과**.
- 별도 오프라인 센서 계약 합성 사례: **15개 모두 기대 결과 충족**.
- 검증 범위: termination/truncation, 평가 중 Q 불변, RNG 포함 재개 동일성, 체크섬, 미완료 로그 복구, 차단/누락, 후보 단계·행동 제한, 입력 시각·순서·단위·보정·상관 출처·리프트 UNKNOWN 처리.

15개 사례는 31개 단위시험과 다른 유형의 실행 보고이며, 이를 합쳐 서로 독립인 실물 시험 46회로 표시하지 않습니다. 카메라 계약은 프레임 참조와 메타데이터만 검사하고 pose payload는 아직 UNKNOWN입니다. 입력 계약이 충족되어도 `actual_motion_permission`은 false입니다.

재실행 명령은 저장소 루트 기준입니다.

python -m unittest discover -s integration_contracts/tests -v
